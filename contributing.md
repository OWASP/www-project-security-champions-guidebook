# Contributing to OWASP Security Champions Guide

The Security Champions Guide is a community project, and we are always delighted to welcome new contributors!

This repository is for the [OWASP project pages](https://owasp.org/www-project-security-champions-guidebook/) only,
so if you want to contribute content to the [actual guide](https://securitychampions.owasp.org/)
then navigate to the [source repository](https://github.com/OWASP/Security-Champions/) to view and modify the content.
